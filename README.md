[codeforces](http://codeforces.com)
===================================

Codeforces is a Russian website dedicated to competitive programming. It
was created and is maintained by a group of competitive programmers from
Saratov State University led by Mikhail Mirzayanov. Since 2013,
Codeforces has surpassed Topcoder in term of active contestants.
Codeforces Round #323 (Div. 2) contest broke all records in term of
registrants: 7248
